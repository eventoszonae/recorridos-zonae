# Zona E · Recorridos virtuales de locaciones

Plataforma de recorridos 3D interactivos para los venues de Zona E.

- `greenhouse/` – piloto Green House (visor Three.js + datos).
  - `data/greenhouse.venue.json` – espacios, objetos, hotspots, exterior (generado desde el modelo Rhino).
  - `data/inventario.json` – fichas de mobiliario y espacios, datos comerciales y contacto. **Se edita sin tocar el 3D.**
  - `fotos/` – fotos de las fichas · `tex/` – texturas.
- `fuente/` – scripts que generan el modelo, la escena y el plano a partir del modelo Rhino.

Nuevas locaciones: una carpeta por venue con la misma estructura.
